# 격자 시뮬레이션과 상태 갱신

## 격자 크기는 격자 데이터에서 구한다

비어 있지 않고 모든 행의 길이가 같은 문자열 배열에서는 다음과 같이 크기를 구한다.

```java
String[] grid = {"....", ".X..", "...."};
int height = grid.length;    // 행 수: 3
int width = grid[0].length(); // 열 수: 4
char cell = grid[1].charAt(1); // 'X'
```

별도의 명령 배열 길이는 명령 개수이며, 명령 문자열 길이는 문자열의 문자 수다.
격자 크기와 우연히 같아도 서로 대체할 수 없다. 읽기만 한다면 문자열 배열을
char[][]로 복사하지 않고 `charAt`으로 각 칸을 확인할 수 있다.
배열과 문자열의 길이 문법은 [리스트와 배열](../java/list-and-array.md)을 참고한다.

## 도착점과 이동 경로를 구분한다

직선으로 여러 칸 이동할 때 도착 칸이 비어 있어도 중간에 장애물이 있을 수 있다.
이동 중 장애물을 만나면 안 되는 규칙이라면, 시작점 다음 칸부터 도착점까지 검사한다.
예를 들어 한 행이 `"..X."`일 때 인덱스 1에서 오른쪽 2칸 이동하면,
도착점 3은 비어 있어도 중간 인덱스 2가 장애물이므로 이동할 수 없다.

직사각형 안에서 한 방향으로 직선 이동할 때 도착점의 범위 검사는 경계 이탈을 판별할 수 있지만,
장애물 검사를 대신하지 못한다. 범위를 벗어난 좌표로 배열이나 문자열에 접근하지 않도록
범위 검사부터 수행한다. 좌표와 범위의 기본 설명은 [BFS](bfs.md)를 참고한다.

## 명령 전체가 성공했을 때만 상태를 확정한다

여러 칸 이동을 하나의 명령으로 취급하고 실패하면 전체를 취소하는 규칙에서는,
중간까지 이동한 상태가 다음 명령에 남아서는 안 된다.

- 실제 위치를 한 칸씩 변경한다면, 명령 시작 위치를 저장하고 실패할 때 복구한다.
- 임시 위치로만 검사한다면, 모든 검사가 성공했을 때 실제 위치에 반영한다.

다음은 한 행에서 오른쪽으로 이동하는 작은 예다.

```java
String row = "...X";
int x = 1;
int distance = 2;
int candidate = x;
boolean valid = true;

for (int step = 0; step < distance; step++) {
    candidate++;
    if (candidate >= row.length() || row.charAt(candidate) == 'X') {
        valid = false;
        break;
    }
}
if (valid) {
    x = candidate;
}
// 인덱스 2는 통과하지만 3에서 실패. 실제 위치 x는 시작 위치 1을 유지
```

임시 위치와 성공 여부는 명령마다 새로 초기화한다. 실패 시 `break`는 검사를 끝내는 역할이고,
실제 위치를 유지하는 것은 성공할 때만 대입하는 구조 덕분이다.
`continue`나 `break` 자체에 복구 기능은 없다.
관련 문법은 [조건문과 반복문](../java/control-flow.md)을 참고한다.
